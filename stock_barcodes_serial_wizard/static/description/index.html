📱 Stock Barcodes Serial Wizard

Odoo 18.0 Stock Management Barcode Scanner Serial Numbers Lot Numbers
📦 Gestión avanzada de números de serie y lotes mediante escáner de códigos de barras

Agiliza la captura de números de serie y lotes en recepciones y envíos con un wizard intuitivo que soporta escaneo de códigos de barras y QR.

🎯 Características Principales

  • Wizard de Escaneo Intuitivo: Interfaz dedicada para escanear números de serie/lote por producto
  • Modo Barcode y QR: Dos modos de visualización adaptados a diferentes flujos de trabajo
  • Búsqueda por SN Proveedor: Localiza automáticamente números de serie usando el código del proveedor
  • Validación en Tiempo Real: Verifica duplicados y errores durante el escaneo
  • Integración con Stock Moves: Actualiza automáticamente las líneas de movimiento de inventario
  • Soporte para Productos Serializados: Manejo específico para productos con tracking serial
  • Configuración Flexible: Parámetros de sistema para personalizar el comportamiento

🔧 Funcionalidades Técnicas

📋 Modelos

  • stock_barcode.lot - Wizard principal para gestión de lotes/seriales
  • stock_barcode.lot.line - Líneas individuales del wizard
  • Herencia de stock.move para acción de wizard

🎨 Vistas Disponibles

  • view_barcode_lot_form_barcode: Modo escáner estándar para flujos de trabajo tradicionales
  • view_barcode_lot_form_qr: Modo inline optimizado para códigos QR y escaneo rápido

⚙️ Parámetros de Configuración

Configurable mediante ir.config_parameter para adaptar el comportamiento a las necesidades del negocio.

📊 Casos de Uso

  • Recepción de mercancía con números de serie individuales
  • Picking de productos serializados para envíos
  • Trazabilidad completa de lotes en producción
  • Control de inventario con códigos de proveedor
  • Validación de albaranes con escaneo masivo de seriales

🚀 Flujo de Trabajo

  1. Desde un movimiento de stock (stock.move), abrir el wizard mediante el botón de acción
  2. El wizard carga automáticamente las líneas de movimiento candidatas
  3. Escanear códigos de barras o QR de los números de serie/lote
  4. El sistema valida y busca por número de serie o SN proveedor
  5. Las cantidades se actualizan en tiempo real
  6. Al confirmar, las líneas de movimiento se actualizan automáticamente

🔗 Dependencias

  • stock - Gestión de inventario base de Odoo
  • barcodes - Framework de escaneo de códigos de barras

💼 Integración con IPTecno Custom

Este módulo se integra perfectamente con el ecosistema de Stock, especialmente con:

  • stock_picking_import_serial_number_extend: Importación masiva desde Excel

Modo Barcode (Diálogo)

Vista en ventana emergente para flujos de trabajo detallados con múltiples seriales.

Modo QR Inline

Vista integrada para escaneo rápido con códigos QR en dispositivos móviles.
